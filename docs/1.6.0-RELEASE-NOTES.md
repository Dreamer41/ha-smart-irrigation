# ZoneFlow 1.6.0 — Greenhouse & indoor climate control

ZoneFlow can now run the climate of a greenhouse or indoor grow space, as
well as water it. Pick **Greenhouse** or **Indoor** under *Where it grows*
when you add a zone (or change an existing zone under Configure → Zone type).
Existing zones are outdoor zones and don't change.

**What's new**

- Fans, vents, misters and a heater, any number of each, from switches, input
  booleans, fans, covers, valves and climate entities.
- Cold, warm, humid and misting rules from an inside temperature sensor and
  optional humidity, light and outside temperature sensors; an outside-air
  check so ventilation never pulls in hotter air.
- The valve is optional: climate-only zones.
- Supervised misting, sensor failsafes, a heater failsafe, backup inside
  temperature sensors, and Manual Hold.
- Status, VPD, Misting Today and Ventilation Allowed sensors; a Greenhouse
  Control switch; about 20 climate settings that appear only when the
  hardware they act on is set up.
- The cards show climate zones. All new texts are translated into the 19
  languages.
- Fixed: a climate-only zone no longer gets the irrigation flow-rate Repairs
  warning.

Read [docs/GREENHOUSE.md](GREENHOUSE.md). **If you have a heater**, please
read its "What ZoneFlow cannot do for you" part: add a hardware frost
thermostat and a backup temperature sensor placed away from the main one.

## Update your dashboard

Outdoor zones: **no dashboard changes needed.** The built-in ZoneFlow card
and overview card update themselves — after updating, do a hard refresh of
the browser (Ctrl+F5) to load the new card.

Greenhouse and indoor zones get these new entities (the built-in card shows
them by itself):

| Entity | Card |
|---|---|
| `sensor.<zone>_greenhouse_status` | status |
| `sensor.<zone>_inside_vpd` | status |
| `sensor.<zone>_misting_today` | status |
| `binary_sensor.<zone>_ventilation_allowed` | status |
| `switch.<zone>_greenhouse_control` | manual controls |
| `switch.<zone>_mist_at_night`, `select.<zone>_misting_trigger`, `select.<zone>_sensor_failsafe`, `select.<zone>_heater_failsafe` | settings |
| about 17 `number.<zone>_…` climate settings (e.g. Heater On Below, Vents Open At, Fans On At, Mist On Time, Sensor Offline After) | settings |

On a hand-built dashboard, add them to your existing cards the same way as
before (Edit dashboard → the card → Show code editor), or paste
[AI_SETUP.md](../AI_SETUP.md) into an AI assistant and ask it to update the
dashboard for 1.6.

## After updating

Nothing — just restart Home Assistant. Existing zones keep working as they
are.
