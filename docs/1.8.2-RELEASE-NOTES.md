# ZoneFlow 1.8.2 — OpenSprinkler stations (beta)

**This is a beta.** It has been tested against a simulated OpenSprinkler, not yet on a real controller. If you use OpenSprinkler, please try it and tell us how it went.

**What's new**

- **An OpenSprinkler station works as a zone's valve.** Pick the station's "Station Enabled" switch as the zone's valve. ZoneFlow starts it with `opensprinkler.run` for the length of the pulse and stops it with `opensprinkler.stop`. Whether it is open is read from the station's "Station Running" sensor.
- **A run that cannot start says so.** A disabled station, a station that does not start within 15 seconds, or a missing "Station Running" sensor is shown as an error, not as a watering that never happened.
- **No master valve for stations.** OpenSprinkler opens its own master with each station, so leave ZoneFlow's master valve empty for these zones.
- Includes the 1.8.1 guide and test fixes. Nothing changes for other valves.

**Limits:** run only one thing at a time on the controller; a station queued behind another one is reported as not started.

## Update your dashboard

No dashboard changes needed.

## After updating

Nothing. If you already use an OpenSprinkler station as a valve, it starts working after the update.
