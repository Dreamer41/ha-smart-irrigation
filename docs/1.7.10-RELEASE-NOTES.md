# ZoneFlow 1.7.10 — Dry-down restart counts the first 24 hours only

**What's fixed**

- **More rain restarts the dry-down only in the first 24 hours.** In 1.7.9 the
  setting **Dry-Down Restarts After More Rain** looked at any 24 hours while a
  dry-down was on, so ordinary rain several days after a storm could start the
  dry-down over. It now counts only rain that falls within 24 hours after the
  dry-down started (or restarted), as the setting's text says. A restart gives a
  new 24 hours, so a storm that keeps going keeps the dry-down on. Rain after
  that does nothing to it, apart from the usual heavy-rain thresholds.
  - Tried in a sandbox Home Assistant: a dry-down two days old did not restart on
    another 12 mm; a dry-down one hour old did.
  - If 1.7.9 already restarted a dry-down that should not have been, set Last
    Significant Rain back by hand (the edit is honored), or leave it: it ends by
    itself after the routine dry-down days.
- The hint text of the setting now also gives the amount in inches (10 mm = 0.4 in).

**Checked before release:** the full test suite, a code review and an outside bug
hunt (nothing found), a copy of real saved data, hassfest, and a sandbox Home
Assistant run read on screen.
