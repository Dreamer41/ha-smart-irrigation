# ZoneFlow 1.6.3 — 15-minute service run

A small update.

**What's changed**

- **New Service Run 15 min button**, next to the 1, 5 and 10 minute ones, for a
  longer flow-calibration test. Like the others it is never counted as
  watering and respects the daily safety cap.

## Update your dashboard

The zone card shows the new button by itself. After updating, do a hard
refresh of the browser (Ctrl+F5) to load the new card. A hand-made dashboard
can add `button.<zone>_service_run_15_min`.

## After updating

Restart Home Assistant. Nothing else to do.
