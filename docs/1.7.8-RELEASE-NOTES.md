# ZoneFlow 1.7.8 — Rolling rain credit for zones updated from 1.7.6, HACS downloads

**What's fixed**

- **A rain mark saved by 1.7.6 now rolls at once.** In 1.7.7 a zone that already
  carried a "rain counted as a watering" mark from 1.7.6 kept the old way until
  that mark ended. Its rain credit read 0.0 mm and "If it watered now" showed a
  full dose in the middle of a wet spell, even after days of heavy rain. Such a
  mark is now adopted into the rolling credit the first time it is read: the days
  of rain before it count again, less the one dose it took. Tried on a copy of a
  real 1.7.6 zone's saved data and on a sandbox zone set up the same way: the
  credit comes out well above one dose and "If it watered now" says nothing is
  needed. Zones that never carried a mark are not affected. In short: the
  watering calculation after heavy rain is better for zones updated from 1.7.6,
  and it keeps correcting itself with the next rain.

**Also**

- **HACS shows a Downloads number.** ZoneFlow is now installed by HACS from a
  `zoneflow.zip` attached to each GitHub release (built and checked
  automatically), which is what HACS counts downloads from. Nothing changes in
  how ZoneFlow works.

**Checked before release:** the full test suite (1,326 tests), a test of the
upgrade from 1.7.6, the copy of real saved data, and a sandbox Home Assistant
run read on screen.

## Update your dashboard

No dashboard changes needed. There are no new entities.

## After updating

Nothing: just restart Home Assistant. Existing zones keep their saved state and
nothing resets.
