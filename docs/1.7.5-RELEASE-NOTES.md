# ZoneFlow 1.7.5 — Nothing written to /config/www, a rain credit fix

**What's changed**

- **ZoneFlow no longer writes anything into your `/config/www` folder.** The
  small loader that makes the cards show on a dashboard opened while Home
  Assistant is still starting now ships inside the integration and is served
  from `/zoneflow_static/zoneflow-loader.js`, next to the card. At the first
  start after updating, ZoneFlow moves its dashboard resource to the new address
  and deletes the old `www/zoneflow/zoneflow-loader.js` it had written (the
  folder only when nothing else is in it). This was asked for in the HACS review.
- **Rain that fell after a "watered by rain" mark is counted again.** When heavy
  rain counted as a watering, the amount used was taken off all the rain of the
  next days, even rain that fell after the mark. A zone marked by two very wet
  days could show "Rain credit since the last watering: 0.0 mm" for days while it
  rained again, and Why? and the next watering gave the full dose. The amount is
  now taken off only the rain of the mark's own day.
- **Last Water Volume and Water Used sensors on Home Assistant 2025.1.** That
  version refuses a sensor that suggests a display unit without a unit
  converter, so these were not created. They are created again (newer versions
  were not affected).
- **A device switched by hand while a greenhouse evaluation was waiting** could
  be switched back before ZoneFlow noticed the manual hold, on newer Home
  Assistant versions. The evaluation now lets pending state changes through first.

## Update your dashboard

No dashboard changes needed. Do a hard refresh of the browser (Ctrl+F5) to load
the new card.

**Dashboards in YAML mode** (`lovelace: mode: yaml`) that added the loader by
hand: change the resource URL from `/local/zoneflow/zoneflow-loader.js` to
`/zoneflow_static/zoneflow-loader.js` (docs/GUIDE.md shows the lines). Until you
do, ZoneFlow keeps the old file and logs a warning at start.

## After updating

Nothing: just restart Home Assistant. Dashboards in storage mode (the usual
kind) are moved to the new loader address by themselves.
