# ZoneFlow 1.7.9 — More rain restarts the dry-down

**What's new**

- **More rain restarts the dry-down.** New setting **Dry-Down Restarts After More
  Rain** in the Rain group: 10 mm to start with, 0 turns it off. While a zone is
  drying out after heavy rain, if at least that much rain falls within any 24
  hours, the dry-down starts over from that moment, so watering waits for the soil
  to dry again. Before, only a new crossing of the heavy-rain thresholds restarted
  it, so 10 mm more on top of an earlier storm changed nothing.
  - It restarts quietly: no alert. The Status and Why? show the new end.
  - After a restart the count starts again from zero.
  - It follows the routine dry-down only. Rain after the routine dry-down has
    ended does not bring it back.
  - If you edit Last Significant Rain by hand, the edit is honored: rain before
    the edit is not counted.
  - Copied with Copy settings and presets, shown in inches with imperial units,
    translated into every language.
  - It is on by default (10 mm) for existing zones. Set it to 0 to keep the old
    behavior.

**Checked before release:** the full test suite (1,339 tests), a code review and
an outside bug hunt (both fixed), the copy of real saved data, hassfest, and a
sandbox Home Assistant run read on screen.

## Update your dashboard

No dashboard changes needed. One new setting per zone, no new sensors.

## After updating

Nothing: just restart Home Assistant. Existing zones keep their saved state and
nothing resets.
