# ZoneFlow 1.7.4 — Valve backup timer, help on every setting, fewer fixed values

**What's changed**

- **Longest Valve Open Time and the backup timer.** A new sensor in the Safety
  group shows the longest your valve is open in one go, worked out from the
  zone's own settings (weekly targets, days between waterings, flow rate, pulses,
  soil and slope, the caps, the deep soak and Service Mode). Check my setup tells
  you what to set as the auto-off timer on the valve itself (Shelly, Tasmota,
  ESPHome, the device's app), as a backup in case Home Assistant stops while the
  valve is open.
- **My Valve's Own Timer.** Type in the minutes you set on the valve. Check my
  setup warns if it is too short, and warns again if a later change makes the
  longest open time grow past it.
- **A "?" on every setting.** Each setting and each group in the zone card's
  Settings has a help button. It opens the matching page on
  [zoneflowirrigation.com/docs](https://zoneflowirrigation.com/docs): one page per
  Settings group, with every setting explained (what it does, its starting value
  and how to pick yours).
- **Simpler Settings popup.** It opens with the everyday settings (flow rate,
  weekly targets, days between waterings). **Show all settings** shows the rest.
- **Why? previews the next watering**: minutes, pulses, soak, and the longest the
  valve is open at once, with the settings as they are now.
- **Check my setup warnings can be ignored**, after a confirmation (for example
  "the flow rate is still the example value" when that really is your flow rate).
  An ignored warning moves to an Ignored list with **Show again**.
- **A valve test at the end of zone setup**: the valve opens for about 2 seconds
  and ZoneFlow says whether it answered and closed. It can be skipped.
- **When Soil Gets Wet During Watering** (zones with a soil probe): **Finish the
  watering** (as before) or **Stop at the wet level**: before each later pulse
  the probe is read, and at the wet level the rest is not given.
- **Water now with minutes is split into pulses** like the zone's own watering,
  so it does not run off on clay or a slope. It can be stopped during the soak.
- **Former fixed values are settings:**
  - **Routine / Deep Soak Minimum Pulse Length** (1 and 5 minutes to start with).
  - **Self-Tuning** switch (on to start with), **Self-Tuning Presses Needed** (3)
    and **Self-Tuning Step** (0.5 days).
  - **Weekly summary time** and **fertilizing reminder time**, chosen at setup
    and under Configure (18:00 and 09:00 to start with).
  - **Deficit Mode Water** goes down to 30 % (it stopped at 50 %).
- **The three Rain Efficiency sliders are shown** (light, moderate and heavy
  rain). They were hidden. How much rain reaches the roots differs between shallow
  and deep rooted plants: see
  [Rain, forecast and frost: the settings](https://zoneflowirrigation.com/docs/settings-rain-forecast-frost).
- **A watering fires on its set day even after a long run.** The early margin
  that keeps the next watering on its day now grows with how long the last run
  took (a long soak on clay used to push the next one a day late).

## Update your dashboard

The ZoneFlow zone card shows everything by itself; do a hard refresh of the
browser (Ctrl+F5) to load the new card. A hand-made dashboard that lists
entities by hand does not show the new ones until you add them. New entities
(`<zone>` is the zone's entity prefix, for example `cucumber_bed`):

- `sensor.<zone>_longest_valve_open_time` and
  `number.<zone>_my_valve_s_own_timer` (safety)
- `switch.<zone>_self_tuning`, `number.<zone>_self_tuning_presses_needed`,
  `number.<zone>_self_tuning_step` (rain and dry-down)
- `number.<zone>_routine_minimum_pulse_length`,
  `number.<zone>_deep_soak_minimum_pulse_length` (pulses)
- `select.<zone>_when_soil_gets_wet_during_watering` (only with a soil probe)

To add them: Edit dashboard, open the card, **Show code editor**, and add the
lines under `entities:`:

```yaml
  - entity: sensor.<zone>_longest_valve_open_time
  - entity: number.<zone>_my_valve_s_own_timer
  - entity: switch.<zone>_self_tuning
  - entity: number.<zone>_self_tuning_presses_needed
  - entity: number.<zone>_self_tuning_step
  - entity: number.<zone>_routine_minimum_pulse_length
  - entity: number.<zone>_deep_soak_minimum_pulse_length
  - entity: select.<zone>_when_soil_gets_wet_during_watering
```

Or paste AI_SETUP.md into an AI assistant and ask it to update your dashboard
for ZoneFlow 1.7.4.

## After updating

Nothing: just restart Home Assistant. Every new setting starts at the value that
used to be fixed (minimum pulses 1 and 5 minutes, self-tuning on with 3 presses
and 0.5 days, summary 18:00, reminder 09:00, the soil probe finishes the
watering), so nothing changes in how your zones water until you move one. Two
things do change by themselves: Water now with minutes is now split into pulses,
and the three Rain Efficiency sliders become visible. Then set **My Valve's Own
Timer** to what you set on the valve, and look at Check my setup.
