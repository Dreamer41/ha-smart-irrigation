# ZoneFlow 1.8.1 — Guide and test fixes

**What's new**

- **Nothing changes in how ZoneFlow waters.** The code is the same as 1.8.0.
- **The AI setup guide (AI_SETUP.md) matches 1.8.0.** It now covers what the
  last 1.8.0 fixes do: the master valve closes after a restart in the middle of
  a run; the leak check needs a few minutes of flow and is not fooled by a meter
  that holds its last rate or reports late; impossible meter and rain readings
  are ignored; a rain sensor stuck wet is caught even when Home Assistant
  restarts daily.
- **The weekly test run on GitHub passes again.** One test (the reference ET0
  average at a tropical latitude) assumed a time of year and failed from late
  autumn.

**Checked before release:** the changed test file; the full test suite is run
before anything is pushed.
