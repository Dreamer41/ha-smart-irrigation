# ZoneFlow 1.6.5 — Water use in litres and rain from weather stations

**What's changed**

- **Water use in litres (gallons).** A new **Zone Flow** setting (the litres per
  minute your zone's valve gives) turns valve minutes into litres. Set it under
  **Configure → Zone flow** (number of heads × flow per head), or it is set for
  you when you work out or measure the flow rate. A flow meter's measured
  litres are used when the zone has one. The zone card now shows the **last
  watering as mm and litres**, plus **Water Used, Past 30 Days** and **Water
  Used This Year** (from 1 January). These are estimates for display; they never
  change when or how much a zone waters. Zones without a Zone Flow or a flow
  meter show mm only, as before.
- **Rain from weather stations.** A new setting, **Rain gauge sensor type**
  (Configure → Zone settings), tells ZoneFlow what the rain sensor reports: a
  **tip counter** (as before), a **rain total** in mm or inches (lifetime, daily
  or weekly, as from Ecowitt, Ambient Weather or Davis), a **rain rate** in mm/h,
  or **rain per reading** (the amount since the previous update, as the Tempest
  *Precipitation* sensor reports it). Existing zones keep working as a tip
  counter. Changing the sensor or the type starts the rain history again. See
  [docs/RAIN-GAUGES.md](RAIN-GAUGES.md). The weather-station types have not been
  tried on real hardware yet, so please report what you find.
- **Fixed:** *Rain Today* could show a sensor's whole history as rain today when
  rain tracking started on a sensor that already held a count.
- **Fixed:** a rain total that starts again every day or week could be taken for
  a sensor glitch on a heavy-rain day and under-count the rain.

## Update your dashboard

The zone card shows the new rows and a new **Water use estimate** settings group
by itself. After updating, do a hard refresh of the browser (Ctrl+F5) to load
the new card.

A hand-made dashboard can add these entities (new in 1.6.5), for example in an
Entities card (Edit dashboard → the card → Show code editor):

```yaml
type: entities
title: Water Use
entities:
  - entity: number.<zone>_zone_flow
  - entity: sensor.<zone>_last_water_volume
  - entity: sensor.<zone>_water_used_past_30_days
  - entity: sensor.<zone>_water_used_this_year
```

Replace `<zone>` with your zone's entity prefix. The litres show nothing until a
Zone Flow is set or the zone has a flow meter. Shortcut: paste `AI_SETUP.md`
into an AI assistant and ask it to update the dashboard for this version.

## After updating

Restart Home Assistant. Then, if you want litres, set **Zone Flow** under
Configure → Zone flow. Nothing else needs doing.
